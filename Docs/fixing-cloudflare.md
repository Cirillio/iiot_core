# Фикс Cloudflare Tunnel и Docker-окружения IIoT

Выжимка технических решений по стабилизации системы (20.04.2026).

## 1. Оптимизация Docker Build
- **Проблема:** Передача контекста сборки весила **2.49 ГБ**.
- **Решение:** Создан `.dockerignore`. Исключены папки `.git`, `bin/obj`, `node_modules` и медиа-активы.
- **Результат:** Контекст сжат до **400 КБ**, сборка ускорилась в 50 раз.

## 2. Сеть и NuGet
- **Проблема:** Ошибка `NU1301` при сборке .NET (блокировка/DNS NuGet).
- **Решение:** В `docker-compose.yml` добавлен `network: host` для этапа `build`. Сборка теперь использует системный VPN/прокси хоста.

## 3. Модернизация Симулятора (Python)
- **Проблема:** Выход за границы адресов Modbus и несовместимость с `pymodbus 3.x/4.x`.
- **Решение:**
    - В `Dockerfile` зафиксирована версия `pymodbus==3.5.4`.
    - Код `main.py` переписан на использование `ModbusSlaveContext` и доступ через `context[slave_id]`.
    - Стартовый адрес смещен с 0 на 1.

## 4. Конфигурация Базы Данных
- **Проблема:** Hardcoded IP `127.0.0.1` в таблице `devices`.
- **Решение:** Выполнен SQL-апдейт `UPDATE devices SET ip_address = 'sim'`. Теперь коллектор видит симулятор по имени сервиса в Docker.

## 5. Стабилизация Cloudflare Tunnel (Прорыв через прокси)
- **Проблема:** Постоянные разрывы (флапанье) каждые 3 минуты из-за таймаутов v2rayN.
- **Решение:**
    - **Protocol:** Форсирован `http2` (TCP), так как прокси не переваривают `quic` (UDP).
    - **Proxy:** Настроен HTTP-порт `10809` (v2rayN).
    - **Network:** Туннель переведен в `network_mode: host`, чтобы видеть прокси на `127.0.0.1`.
    - **Heartbeat:** Ускорен до 5 секунд (`--heartbeat-interval 5s`), чтобы держать канал активным.
    - **Bypass:** Добавлен `NO_PROXY=localhost,127.0.0.1`, чтобы туннель не искал Web API в интернете.

## 6. Исправление API (Swagger & Redirects)
- **Проблема:** Статус "Down" в Dashboard из-за циклического редиректа HTTPS.
- **Решение:** В `Program.cs` закомментирован `app.UseHttpsRedirection()`. Терминация SSL теперь только на стороне Cloudflare.
- **Swagger:** Доступен всегда (не только в Dev), путь: `https://<domain>/swagger/`.
